# 捂脸哭宇宙 / Facepalm-Cry Universe

静态表情网站：156 张可下载 GIF、奶蛙专区、数量暴增专区、透明底默认推荐 / 白底备选、ZIP 整包及浏览器本地自定义 GIF 生成。

数量暴增保留倍数文字，其他系列的 GIF 移除了全部说明文字。名称保留在网页中，不会写入下载文件。图片拖动指向同一 GIF 原文件。首页包含可跳过的宇宙轨道入场动画，系统设置「减少动态效果」时直接进入页面。

直接在静态 HTTP 服务下使用。资源均采用相对路径，兼容 GitHub Pages 项目站点。GitHub Pages 配置 `main` 分支、`/ (root)`；`.nojekyll` 禁用 Jekyll。

白底 ×2 成品曾经在电脑微信实测出现「添加到表情」。其它成品采用相同编码；在线自定义生成需在实际客户端确认。素材参考及使用说明见 `about.html`。gifenc 使用 MIT 许可证；第三方角色素材不包含商业授权。
